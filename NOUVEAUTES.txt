PLANNING FAMILIAL V5.3.5 — CHURCH SCHEDULE REBUILD

Cette version reconstruit complètement la gestion du dimanche.

Cause corrigée :
- Les anciennes versions mélangeaient les données Sunday avec recurringSchedules et d'anciens essais.
- Un ancien Recovery pouvait donc continuer à apparaître même après une modification dans Calendar.

Nouvelle architecture :
- Edan possède maintenant une seule base dédiée : edan.churchSchedule.
- Calendar lit edan.churchSchedule.
- Validate écrit dans edan.churchSchedule.
- Remove supprime dans edan.churchSchedule.
- La page Sunday lit edan.churchSchedule.
- Il n'y a plus de deuxième source Sunday.

Important :
- Au premier lancement de V5.3.5, les anciennes sélections Sunday expérimentales sont volontairement effacées UNE SEULE FOIS.
- La page Sunday doit donc être vide au départ.
- Ensuite :
  1. Calendar
  2. cliquer sur un dimanche
  3. choisir Sound (FOH) ou Recovery
  4. Validate
  5. fermer Calendar
  6. le service confirmé apparaît sur Sunday.
- Une modification ou suppression depuis Calendar met à jour la page Sunday avec la même donnée.
